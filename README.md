# 📱 Calculadora Apple

 Recriação da calculadora clássica do iOS usando HTML, CSS e JavaScript puro. 

O objetivo do projeto foi treinar a construção de interfaces fiéis ao design original da Apple e praticar a lógica de manipulação do DOM e expressões matemáticas no navegador.

---

## 💻 Como ficou
Você pode testar a calculadora rodando direto no seu navegador:
👉 **[Acessar Calculadora Online](https://andrerodriguesluz.github.io/calculadora-apple/)**

---

## 🛠️ Recursos implementados
- **Operações básicas:** soma, subtração, multiplicação e divisão.
- **Apagar inteligente (`⌫`):** remove o último caractere caso você erre algum número digitado.
- **Limpar tudo (`C`):** zera a tela para iniciar um novo cálculo.
- **Porcentagem (`%`):** cálculo direto de porcentagem na expressão.
- **Design iOS:** suporte a visual escuro com botões arredondados no padrão da Apple.

---

## 📂 Tecnologias
- **HTML5:** estrutura dos botões e tela.
- **CSS3:** layout com Grid e Flexbox, cores e animações de clique.
- **JavaScript:** lógica de cálculo e controle do display.
